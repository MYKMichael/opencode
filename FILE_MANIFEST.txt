使用说明
────────────────────────────────────────────────────────────────

快速开始:
  1. bun run build              # 编译 OpenCode
  2. node verify_acp.js         # 运行验证脚本

  或:
  ./quick_test_acp.sh           # 一键测试

查看示例:
  node example_usage.js         # 显示菜单
  node example_usage.js 1       # 运行示例 1
  node example_usage.js all     # 运行所有示例

阅读文档:
  ACP_VERIFICATION_README.md    # 使用指南
  ACP_TECHNICAL_DOC.md          # 技术文档
  QUICK_REFERENCE.md            # 快速参考

────────────────────────────────────────────────────────────────
集成指南
────────────────────────────────────────────────────────────────

集成到 IDE 插件:

1. 复制文件:
   - verify_acp.js → 你的插件目录

2. 引入类:
   const { ACPClient } = require('./verify_acp');

3. 创建实例:
   const client = new ACPClient({ workingDir: projectPath });

4. 自定义处理器:
   client.handleWriteTextFile = async (params) => {
     // 调用 IDE 的 UI 确认对话框
   };

5. 启动使用:
   await client.start();
   await client.initialize();
   await client.createSession();
   await client.sendPrompt(userInput);

详细集成示例见: example_usage.js 的示例 8
